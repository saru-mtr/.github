# .github: organização saru-mtr

Repositório meta da organização `saru-mtr` no GitHub: perfil público, diretrizes de contribuição compartilhadas, modelos de issue/PR, segurança e workflows compartilhados. Regras universais em `~/.claude/AGENTS.md`; regras da pasta SARU em `../AGENTS.md`.

## Onde está cada coisa

| Caminho | O que é |
|---|---|
| `profile/README.md` | Perfil público da organização `saru-mtr` no GitHub |
| `CONTRIBUTING.md` | Diretrizes de contribuição compartilhadas entre repositórios |
| `PULL_REQUEST_TEMPLATE.md` | Modelo padrão de Pull Request |
| `SECURITY.md` | Política de segurança e reporte de vulnerabilidades |
| `CODEOWNERS` | Definição de donos de código |
| `.github/workflows/` | Workflows reutilizáveis de CI/CD da organização |

## Regras

1. Mudanças aqui afetam o comportamento público ou os padrões de toda a organização `saru-mtr`.
2. Texto, commits e PRs em português (regra global).
3. Qualquer alteração em modelos ou diretrizes de contribuição deve refletir as decisões registradas em `saru-empresa/docs/decisions.md`.
